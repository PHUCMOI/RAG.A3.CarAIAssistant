## Lỗi phát hiện và xử lý

- Model diễn đạt 60 tháng là “gấp đôi” 36 tháng: thêm prompt và kiểm tra từ chối tỷ lệ suy diễn; gọi Bedrock thật lại đã trả đúng hai thời hạn. Xem `qa-artifacts/compare-after-fix.txt`.
- CSS menu quản trị trên mobile có thể làm tràn trang: tăng độ ưu tiên style ẩn/mở menu, giới hạn chiều rộng dropdown; test mobile đã qua.
- Test menu dùng thao tác desktop trên mobile: mở lại menu sau điều hướng và bấm bên ngoài vùng dropdown; giữ kiểm tra focus/đóng menu.
- Test đăng nhập chat chưa mock endpoint compose mới: cập nhật dữ liệu mock; đồng thời frontend từ chối phản hồi compose rỗng để không render undefined.
